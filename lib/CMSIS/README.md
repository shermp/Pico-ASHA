# ARM CMSIS Core & DSP libraries

This directory contains subsets of the ARM DSP and Core libraries.

The complete libraries were not required for Pico-ASHA. Only the filtering and support components of the DSP library are included.

# Included versions

- [CMSIS-DSP](https://arm-software.github.io/CMSIS-DSP/latest/index.html) - Version 1.17.0
- [CMSIS-Core (Cortex-M)](https://arm-software.github.io/CMSIS_6/latest/Core/index.html) - Version 6.2.0
