# Web UI

<a href="../web-ui/">Launch the Pico-ASHA Web UI</a>

The Web UI can be installed from your browser's **Install app** action. After the first successful load, its interface is available offline; connecting to the adapter still requires Web Serial support and permission to access the device. When you reopen the UI, it automatically reconnects to an available Pico-ASHA adapter that you have previously authorized. For a new adapter, use the Connect button to choose it from the browser's device picker.
